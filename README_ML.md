# Vaso VOC Crisis Prediction Model v2.0

## Overview
Machine learning model to predict vaso-occlusive crisis risk in sickle cell disease patients without requiring wearables.

## Features Added in v2.0
✓ Temporal features (pain trends, consecutive dehydration)
✓ Treatment factors (hydroxyurea, transfusions, adherence)
✓ Women's health (menstrual cycle)
✓ Environmental triggers (altitude, humidity, temp drops)
✓ Data quality validation
✓ Feature importance analysis
✓ Calibration curves
✓ Risk trend comparison
✓ Production-ready API
